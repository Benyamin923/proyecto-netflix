# Proyecto Netflix

Proyecto web inspirado en Netflix desarrollado como parte de la materia Implementa Software Multiplataforma.

## Tecnologías utilizadas

* HTML
* CSS
* JavaScript
* PHP
* MySQL
* XAMPP

## Funcionalidades

* Registro de usuarios
* Inicio de sesión
* Gestión de sesiones
* Catálogo de películas
* Búsqueda de contenido
* CRUD completo de usuarios
* Conexión a base de datos MySQL
